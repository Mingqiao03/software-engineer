# 组内基建 · 全景头脑风暴

用处有两层：

1. **访谈弹药**——去聊的时候，心里有这张全图，才不会漏问、才知道往哪挖
2. **选切片**——本项目最终只能做**一个系统**，这张图帮你挑出最有价值的那一块

⚠️ **不要试图把整张图做成一个项目**。课程要求是"一个系统 + 两个不同原型"，
不是产品路线图。全做 = 需求分析变浅 + 两个原型做不出来 = 直接失分。

## 一、功能域全景

按"使用场景"分八块。每块列了具体事项和**现在的痛点**。

### 1. 对外门户与身份

| 事项 | 现在的样子 / 痛点 |
|---|---|
| 实验室主页 | 常年不更新，成员毕业了还挂在上面 |
| 论文列表 | 手工维护；新论文发出来忘了加 |
| 论文自动同步 | 接 DBLP / Google Scholar / arXiv 自动抓取 |
| 组内 Wiki / 知识库 | 没有，或建了没人写、没人看 |

| 英文版页面 | 招国际生、对外合作需要 |

### 2. 新人入门（onboarding）

| 事项 | 现在的样子 / 痛点 |
|---|---|

## 二、冲突地图（这门课真正值钱的部分）

基建工具做不好，通常不是技术问题，是**干系人目标打架**。
下面这些冲突是真实的，而且正是评分细则奖励的"需求冲突与价值权衡"。

| # | 冲突 | 一边 | 另一边 |
|---|---|---|---|
| 1 | **透明度 vs 隐私** | 导师要看到真实进度和卡点 | 学生怕暴露"没进展"、被拿来比较 |
| 2 | **统一 vs 顺手** | 组里想统一工具和流程 | 每个人都有自己的习惯，换不动 |
| 3 | **自动化 vs 可信** | AI 自动总结省事 | 摘要会失真、漏记关键结论，导师不敢信 |
| 4 | **降低门槛 vs 安全** | 新人要快速上手 | 权限一开就有安全风险 |
| 5 | **维护成本 vs 收益** | 工具确实有用 | 谁长期维护？学生流动性高，人一走就烂尾 |
| 6 | **要全 vs 没人写** | 知识库越全越好 | 没人愿意写、愿意维护 |

> 选切片时，优先选**冲突真实且激烈**的那块。有冲突才有需求权衡可分析，
> 才能写出"需求优先级与冲突"那 8 分。

## 三、干系人速查

| 干系人 | 想要什么 | 怕什么 |
|---|---|---|
| 新生 | 快速上手、少踩坑、有人问 | 问多了被嫌烦、找不到人 |
| 老生 / 博士生 | 少被打断、专注自己研究 | 被摊派维护工作 |
| 导师 | 掌握进度、资源用得好、组里有产出 | 被蒙在鼓里、资源浪费 |
| 实验室管理员 / 秘书 | 流程清楚、账目可查 | 反复返工 |
| 即将毕业者 | 顺利交接、成果被继承 | 走了之后工作没人管 |
| 外部访客 / 合作者 | 快速了解组里、能联系上 | 信息过时 |

## 四、切哪一块？（选型建议）

课程约束回顾：**一个系统 + 两个真正不同的原型 + 可核实的获取证据 + 可量化的评估**。

按这四条筛，第一梯队是下面三个：

### 🥇 A. 新生入门助手

- **冲突**：新人要快 ↔ 老生不愿重复答疑 ↔ 导师要新人尽早产出（冲突表 #1 #2 #5）
- **两个原型**（差异维度 = 规则 vs AI、人机职责）：
  - P1 结构化知识库 + FAQ：人工维护规则，答案可追溯
  - P2 AI 助手：自动回答 + 挂原始出处 + 答不了就转人
- **证据好拿**：访谈新老生；**历史答疑记录**（微信群/邮件，这是现成的真实语料，含金量高）
- **评估可量化**：新人完成关键任务的时间、问题一次解决率、老生被打断次数

### 🥈 B. 算力 / GPU 资源管理

- **冲突**：公平 ↔ 效率（冲突表 #1 #5）
- **两个原型**（差异维度 = 规则 vs 预测、集中 vs 本地）：
  - P1 规则排队 + 配额
  - P2 基于使用数据的调度 / 预测
- **证据特别好**：**机器日志是真实数据**，可做仓库挖掘式分析（细则明列的合法方法）
- **评估可量化**：卡利用率、平均等待时间、公平性指标（基尼系数之类）
- **风险**：要拿到日志和历史数据，得先搞定管理员

### 🥉 C. 组会记录与总结

- **冲突**：记录要准 ↔ 自动摘要会失真；透明度 ↔ 隐私（冲突表 #1 #3）
- **两个原型**（差异维度 = 人机职责分配）：
  - P1 结构化纪要模板 + 人工 + 待办追踪
  - P2 AI 转写 + 自动摘要 + 待办提取（人只审核）
- **证据好拿**：访谈 + **历史组会纪要**（现成的）
- **风险**：录音涉及隐私与知情同意，伦理处理要规范

### 不推荐单独做

- **实验室主页 / 论文列表**：容易撞上细则点名的"静态展示"，需求难点不足
- **整套基建平台**：范围爆炸，必然做不出两个原型
