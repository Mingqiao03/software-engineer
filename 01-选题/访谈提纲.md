# 泛访谈提纲（第 5 周，2026-10-14）

> 三份调研（`调研/`）的点已经收敛进这份提纲的第 5 节兜底清单。
> 这份提纲是**拿去用的**，不是拿去读的。

## 0. 先明确：这次访谈要什么

| | |
|---|---|
| **目的** | **不定题**。只收痛点，找冲突 |
| **要产出** | 不是"需求列表"，是**"谁的诉求跟谁打架"** |
| **副产品** | 访谈纪要 —— 这就是 W6 第一次检查要交的"需求获取证据" |
| **时长** | 每人 30–40 分钟 |

## 1. 三条纪律（做不到就白访）

1. **不问"你们缺什么工具"** —— 问"你们现在**怎么做的**、卡在哪一步"。
   问缺什么 → 得到功能列表（细则明确不给分）；问怎么做 → 得到需求（给分）。
2. **不介绍你的方案**，直到访谈结束。中途说出来 = 污染回答，后面全是附和你。
3. **记原话，不记你的总结**。"他说流程很乱"是废的；"他说'每次都要在群里问三遍才知道哪台机器空着'"是证据。

## 2. 样本（3–5 人）

| 角色 | 人数 | 找谁 |
|---|---|---|
| 新生 | 2 | 今年的新生，最好不同方向 |
| 老生 / 博士生 | 2 | 在组时间 ≥1 年 |
| 导师 或 管理员 | 0–1 | 约得到就约，约不到别硬凑（纪要里写明限制） |

> ⚠️ 找不到某类人时，**如实写明限制**，不要编。这是课程红线。

## 3. 开场 + 知情同意（照着念）

> "我在做课程的一个项目，想了解咱们组里日常公共事务是怎么运转的，比如机器、文献、组会这些。
> 我想听真实的吐槽，越具体越好，没有标准答案。
> 我**不会**把内容转给导师，报告里会**匿名**（用 P1/P2 这种编号），提到的人也用化名。
> 问我能不能记笔记？**【如果要录音】另外单独问：能不能录音？只用于我自己整理，整理完删掉。**
> 如果你觉得哪个问题不想答，跳过就行。"

**要点**：匿名承诺 + 录音单独同意 + 可以跳过。这是伦理要求，也是 W6 能写进报告的一笔。

## 4. 主体问题（先开放，按块走）

**块 A · 现状与日常（暖场，别急着挖）**

1. 你最近一周在组里做了哪些**跟自己的研究无关**的事？
2. 从早上到工位到晚上走，哪些环节跟"组里的公共事务"有关？

**块 B · 痛点（开始挖）**

3. 这些里面，哪件事**最花时间 / 最烦**？为什么？
4. 有没有"**不知道找谁**"或者"**不知道东西在哪**"的时候？举个例子？
5. 有没有**重复做同一件事**，或者**被一遍遍问同一个问题**？

**块 C · 冲突（最重要的一块，别跳）**

6. 组里在 **[某个环节]** 这件事上，大家的做法**一致**吗？
7. 你有没有因为组里的某个流程/工具，**跟人有过不同意见**？
8. 有没有"**规定是这么做，但大家实际不这么做**"的事？
9. 如果组里要统一一个做法，你觉得**谁会不高兴**？为什么？

**块 D · 变化与新人**

10. 这半年组里在这块有什么变化？新人来了通常会问什么？
11. （对老生）你被新问过最多的三个问题是什么？

> 块 C 是金矿。**细则里"需求优先级、冲突与权衡"那 8 分，全靠这里挖出来的东西。**

## 5. 分主题追问（点清单 · 兜底用）

主体问完了，对着这张表查漏。**问题只是提示，别照着念。**

### 5.1 机器 / 算力
- 你现在怎么知道哪台机器/哪张卡空着？问人？群里喊？有地方看吗？
- 你占着一台机器的时候，别人怎么知道？你怎么告诉别人？
- 任务跑完/你走了，谁负责释放？有没有忘了释放、卡被占着没人用的情况？
- 有没有"某人占着卡但看起来没在跑"的情况？你们怎么处理？
- 机器坏了怎么报修？谁管？多久能修好？
- 环境（conda/docker）是各装各的吗？复现别人的结果难不难？
- 数据集/模型是各下各的吗？有没有重复下载、或者找不到在哪的情况？

### 5.2 文献（按项目/方向）
- 你做某个方向的时候，怎么看这个领域的论文？谁给你推荐的？
- 你的论文笔记记在哪？别人能看见吗？
- 组里有共享文献库吗？谁在用？为什么不用？
- 师兄/学姐毕业了，他那个方向的积累（读过的论文、踩过的坑）**去哪了**？
- 新人接手一个方向，怎么知道该读哪些论文？
- 投稿前，引用格式、引用核查这些怎么弄？

### 5.3 组会
- 组会记录谁做？记完发哪？有人看吗？
- 会上定的事（待办），后面有人跟吗？怎么跟？
- 想不起来上次组会说了什么，你会怎么办？
- （如果讨论录音）如果组会录音+自动生成纪要，你觉得**谁会反对**？为什么？

### 5.4 门户 / 论文列表
- 组里的主页你多久看一次？新论文加上了吗？
- 外面的人（想报考的学生、合作者）怎么了解咱们组？他们会问什么？
- 主页/论文列表谁维护？多久更新？

### 5.5 新人入门 / 知识沉淀
- 你刚进组的时候，最难搞清楚的是什么？
- 那时候你问了谁？问了几次？
- 现在有没有"新人必问"的清单？谁维护？
- 组里的规矩（服务器怎么用、代码怎么管）写在哪？新人怎么知道？
- 组里在做什么方向、谁在做，新人怎么知道？

## 6. 收尾

12. 如果组里**只能改善一件事**，你选哪个？为什么是它？
13. 还有谁你觉得我该去聊？
14. 后面如果我有追问，能不能再找你？（征得同意再留联系方式）

## 7. 记录模板（W6 要交的证据）

每人一份，**当天整理**：

```
受访者编号：P1         角色：研一新生         时间：10-16 15:30
方式：面谈 30min   录音：有/无（已获同意）

【原话要点】（尽量原样，别加工）
- "..."
- "..."

【我读到的痛点】
- 机器占用：靠群里问，经常问了半天没人回

【我读到的冲突】
- 有人觉得该强制登记，有人觉得填表太麻烦 / 有人不愿别人知道自己在跑什么

【待验证】
- 他说"大家都觉得X很烦" —— 需要问别人确认，不能只信一个人
```

> 报告里用 **P1/P2/P3** 编号，不写真名。原始纪要在手上留着备查（老师可能要）。

## 8. 注意事项

- **匿名化**：报告用编号；提到的人也用化名
- **录音**：单独同意；不同意就手记。整理完删录音
- **区分事实与意见**："流程很乱"是意见；"每次要问三遍才知道哪台机器空着"是事实。两个都记，但要分开
- **别附和**：他说完了不要接"对对对我也觉得"，那会引导他
- **一个人 ≠ 全体**：他说"大家都这么想"，必须再问别人验证

## 9. 访谈之后

1. 当天整理纪要（第 7 节模板）
2. 汇总所有人的**冲突线索** → 哪条冲突被提到最多、最激烈？
3. **那条冲突 = 你的选题方向**
4. 然后才去写选题说明和建议书
